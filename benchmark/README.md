# Benchmarking pipeline

Utilities to run and analyze hyperparameter scans with design scripts
on a standard set of benchmark problems. See "benchmarks.json" for a list of
benchmarks and their specifications (i.e. input pdb and contig string).

## Usage

Each step requires all the jobs submitted by the previous step to have
finished.

1. Sweep hyperparameters:

    ./sweep_hyperparam.py --benchmarks rsv5-1 --job_list jobs.list \
        --num_per_condition 10 --num_per_job 2 --out run1/run1 \
        --args "--temperature 0.05:0.1:0.2 --tmpl_conf 0.9:1 --cautious" \
               "--temperature 0.1:0.2 --tmpl_conf 0.7:0.8 --cautious" 

2. Score outputs:

    ./score_designs.py --chunk 20 --job_list jobs.score.list run1/ 

3. Compile metrics:

    ./compile_metrics.py run1

Step 1 runs the inpainting script on the "rsv5-1" benchmark with all
combinations of --temperature in {0.05, 0.1, 0.2} and --tmpl_conf in {0.9, 1},
plus all combinations of --temperature in {0.1, 0.2} and --tmpl_conf in {0.7,
0.8}.

By default, sweep_hyperparams.py will submit an array job to slurm and return
the slurm job ID.  Inputting --command will use a different design script and
putting "--benchmark all" will run every benchmark in benchmarks.json.
Inputting --gpu a4000 will run jobs on a4000's instead of rtx2080's, which is
default.

Step 2 runs AF2 monomer predictions on a folder of designs, splitting them
across multiple jobs with 20 designs each. This will also submit an array job
and return the ID. The AF2 prediction script will also read design metadata
about the location of the motif and compute motif RMSDs.

Step 3 combines all completed AF2 metrics into a single table, adding design
run metadata from the trb file (each command-line flag becomes a column), and
saves it to combined_metrics.csv.

## Manual job submission

Scripts are included for manually submitting job lists generated by
sweep_hyperparam.py and score_designs.py. For example, an alternative to step 1
above is (note the --no_submit flag and the output to stdout):

    ./sweep_hyperparam.py --benchmarks rsv5-1 --job_list jobs.list \
        --num_per_condition 10 --num_per_job 2 --out run1/run1 --no_submit \
        --args "--temperature 0.05:0.1:0.2 --tmpl_conf 0.9:1 --cautious" \
               "--temperature 0.1:0.2 --tmpl_conf 0.7:0.8 --cautious"  > jobs.list

Followed by (the 3rd argument is optional and the name to assign to the slurm
job):

    ./gpu_array_submit.sh jobs.list run1
